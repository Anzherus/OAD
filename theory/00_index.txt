================================================================
БЫСТРЫЙ СПРАВОЧНИК ПО ФОРМУЛАМ
================================================================

Среднее:
  mean = (1/n) * Σ |amount_i|

Стандартное отклонение (несмещённое):
  s = sqrt( (1/(n-1)) * Σ (|amount_i| - mean)^2 )

Квантиль q:
  pos = (n-1) * q
  result = x[floor(pos)] + frac(pos) * (x[floor(pos)+1] - x[floor(pos)])

Межквартильный размах:
  IQR = Q3 - Q1

Граница выброса (Тьюки, крайний):
  fence = Q3 + 3 * IQR

Доля пыли:
  dustShare = count(0 < |amount| < threshold) / count(|amount| > 0)

Закон Бенфорда:
  P(d) = log_10(1 + 1/d),  d = 1..9

MAD (Нигрини):
  MAD = (1/9) * Σ_{d=1}^{9} |obs(d) - P(d)|

Интерпретация MAD:
  < 0.015  --> приблизительное соответствие
  >= 0.015 --> слабое соответствие

Burst detection:
  Окно [t_start, t_start + W] содержит >= K событий --> всплеск
  W = burstWindowSec (по умолчанию 3600 сек)
  K = burstMinEvents (по умолчанию 8)

Вес ребра графа:
  w(A -> B) = Σ |amount_i| для всех транзакций A -> B
