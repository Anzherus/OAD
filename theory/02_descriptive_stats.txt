ОПИСАТЕЛЬНАЯ СТАТИСТИКА ТРАНЗАКЦИОННЫХ ДАННЫХ
================================================================

Файл: src/domain/stats/describe.ts
Функция: describeTransfers(rows, dustThresholdNative)

НАЗНАЧЕНИЕ
================================================================

Описательная статистика даёт первичную характеристику набора
транзакций: масштаб операций, типичные суммы, разброс, наличие
аномально крупных или мелких переводов.

В криминалистике описательные метрики используются для:
  - быстрой оценки "профиля" адреса
  - сравнения с другими адресами или периодами
  - выявления аномалий для дальнейшего изучения

ВЫЧИСЛЯЕМЫЕ МЕТРИКИ
================================================================

Входные данные: массив |amountNative| (абсолютные значения сумм),
отсортированный по возрастанию.

1. COUNT (количество событий)
   n = rows.length
   Общее число транзакций в выборке.

2. SUM_IN (сумма входящих)
   sumIn = Σ amount_i,  где amount_i > 0
   Суммарный объём полученных средств.

3. SUM_OUT (сумма исходящих)
   sumOut = Σ |amount_i|,  где amount_i < 0
   Суммарный объём отправленных средств.

4. NET (чистый поток)
   net = sumIn - sumOut
   Положительное значение: адрес накапливает средства.
   Отрицательное значение: адрес тратит больше, чем получает.

5. MEAN_ABS (среднее абсолютных значений)
   mean = (1/n) * Σ |amount_i|
   Чувствительно к выбросам. Если mean >> median -- есть крупные
   нетипичные транзакции.

6. MEDIAN_ABS (медиана абсолютных значений)
   Значение, делящее отсортированный ряд пополам.
   Для нечётного n: median = x[(n-1)/2]
   Для чётного n: median = (x[n/2-1] + x[n/2]) / 2
   Устойчива к выбросам. Отражает "типичную" сумму транзакции.

   Реализация через квантильную функцию:
   pos = (n - 1) * q
   base = floor(pos)
   result = x[base] + (pos - base) * (x[base+1] - x[base])

7. STDEV_ABS (стандартное отклонение)
   variance = (1/(n-1)) * Σ (|amount_i| - mean)^2
   stdev = sqrt(variance)
   Используется несмещённая оценка (делитель n-1, формула Бесселя).
   Высокое stdev при малой медиане указывает на неоднородность
   потоков -- характерно для mixing-сервисов.

8. Q1_ABS, Q3_ABS (квартили)
   Q1 = quantile(sorted_abs, 0.25)  -- первый квартиль
   Q3 = quantile(sorted_abs, 0.75)  -- третий квартиль
   25% значений ниже Q1, 75% значений ниже Q3.

9. IQR (межквартильный размах)
   IQR = Q3 - Q1
   Мера разброса, устойчивая к выбросам.
   Используется в правиле Тьюки для обнаружения выбросов.

10. DUST_SHARE (доля "пыли")
    dustCount = количество транзакций, где 0 < |amount| < threshold
    nonZero = количество транзакций с |amount| > 0
    dustShare = dustCount / nonZero

    По умолчанию threshold = 0.00001 (BTC) или 0.00001 (ETH).
    Значение > 0.35 (35%) помечается флагом dustHeavy.

11. MAX_ABS (максимальная сумма)
    maxAbs = max(|amount_i|)
    Используется совместно с IQR для выявления крупных выбросов.

ПРАВИЛО ТЬЮКИ ДЛЯ ВЫБРОСОВ
================================================================

Классическое правило обнаружения "крайних выбросов":

  fence = Q3 + 3 * IQR

  Если maxAbs > fence И n >= 5 -- флаг largeOutlier = true.

Коэффициент 3 (а не стандартный 1.5) используется для выявления
именно крайних выбросов, а не просто нетипичных значений.

Криминалистический смысл: крупная нетипичная транзакция может
означать вывод накопленных средств, получение оплаты или
консолидацию активов.

ПРИМЕР ВЫЧИСЛЕНИЙ
================================================================

Допустим, 5 транзакций с суммами: [0.5, 1.0, 0.8, 0.3, 10.0]
Отсортировано: [0.3, 0.5, 0.8, 1.0, 10.0]

n = 5
mean = (0.3+0.5+0.8+1.0+10.0) / 5 = 2.52
median = 0.8 (средний элемент)
Q1 = quantile(0.25) ≈ 0.5
Q3 = quantile(0.75) ≈ 1.0
IQR = 1.0 - 0.5 = 0.5
stdev = sqrt(((0.3-2.52)^2 + ... + (10.0-2.52)^2) / 4) ≈ 4.18
fence = 1.0 + 3*0.5 = 2.5
maxAbs = 10.0 > 2.5 --> largeOutlier = true

Вывод: транзакция на 10.0 является крайним выбросом.

function quantile(sorted: number[], q: number): number {
  const pos = (sorted.length - 1) * q
  const base = Math.floor(pos)
  const rest = pos - base
  return sorted[base] + rest * (sorted[base+1] - sorted[base])
}
