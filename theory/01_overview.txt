ОБЩИЙ ОБЗОР ПРОЕКТА
================================================================

Данный учебный проект демонстрирует применение статистических
методов к анализу транзакционных данных криптовалют (Bitcoin и
Ethereum) в контексте криминалистического исследования цифровых
следов.

Проект реализован как веб-приложение на стеке:
  - React 19 + TypeScript
  - Vite (сборщик)
  - Tailwind CSS (стили)
  - Recharts (графики)
  - @xyflow/react (граф транзакций)
  - Zod (валидация данных)

ПОТОК ДАННЫХ В ПРИЛОЖЕНИИ
================================================================

1. Пользователь вводит адрес кошелька (BTC или ETH)
2. Адаптер запрашивает историю транзакций через публичный API
3. Транзакции нормализуются в единый формат NormalizedTransfer
4. buildFullReport() вычисляет все статистики и строит граф
5. UI отображает результаты: граф, метрики, графики

НОРМАЛИЗОВАННАЯ ТРАНЗАКЦИЯ (NormalizedTransfer)
================================================================

Единый формат для BTC, ETH и импортированных данных:

  id            -- уникальный идентификатор (txid / hash)
  timestampSec  -- время в Unix-секундах
  from          -- адрес отправителя (lowercase)
  to            -- адрес получателя (lowercase)
  amountNative  -- сумма в нативных единицах со знаком:
                   > 0 означает входящий поток к фокусному адресу
                   < 0 означает исходящий поток от фокусного адреса
                   = 0 контрактный вызов без передачи ETH
  asset         -- 'BTC' | 'ETH' | 'UNKNOWN'
  eventType     -- метка события (для импортированных данных)
  rawRef        -- ссылка на исходную запись

ФОКУСНЫЙ АДРЕС
================================================================

Фокусный адрес (focus address) -- это адрес кошелька, который
исследуется. Все суммы вычисляются относительно него:
  - транзакция входящая, если фокус является получателем (to)
  - транзакция исходящая, если фокус является отправителем (from)

Это стандартный подход в блокчейн-аналитике: анализ "с точки
зрения" конкретного адреса.

ИСТОЧНИКИ ДАННЫХ
================================================================

Bitcoin -- mempool.space REST API (https://mempool.space/api)
  Не требует ключа. Лимит: 25 транзакций за запрос.
  Пагинация через параметр lastSeen (txid последней транзакции).
  Данные включают: vin (входы), vout (выходы), block_time.

Ethereum -- Etherscan API V2 (https://api.etherscan.io/v2/api)
  Требует бесплатный API-ключ (etherscan.io/myapikey).
  Параметр chainid=1 для Ethereum mainnet.
  Лимит free tier: 5 запросов/сек, 100 транзакций за запрос.
  Данные включают: hash, from, to, value (в wei), timeStamp.

Импорт файлов -- CSV или JSON с полями:
  timestamp, amount, from, to, event_type
  Суммы со знаком относительно фокусного адреса.

КЭШИРОВАНИЕ
================================================================

Все HTTP-запросы кэшируются в памяти браузера (Map) с TTL 90 сек.
Ключ кэша: URL запроса или составной ключ "etherscan:адрес:страница".
При перезапуске dev-сервера кэш очищается.
Цель: снизить нагрузку на API при повторных запросах.
