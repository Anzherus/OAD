================================================================
ВРЕМЕННОЙ АНАЛИЗ ТРАНЗАКЦИЙ
================================================================

Файл: src/domain/stats/temporal.ts
Функция: temporalFromTransfers(rows, burstWindowSec, burstMinEvents)

НАЗНАЧЕНИЕ
================================================================

Временной анализ исследует не суммы, а моменты времени транзакций.
Цель -- выявить паттерны активности: равномерный (ручной) ввод,
автоматизированные серии, периодические всплески.

В криминалистике временной анализ применяется для:
  - установления факта автоматизации (бот, скрипт)
  - выявления координированных действий нескольких адресов
  - определения временных зон активности (часовой пояс владельца)
  - обнаружения mixing-сервисов (характерные временные паттерны)

ИНТЕРВАЛЫ МЕЖДУ ТРАНЗАКЦИЯМИ
================================================================

Алгоритм:
1. Транзакции сортируются по timestampSec по возрастанию
2. Для каждой пары соседних транзакций вычисляется интервал:
   delta_t[i] = timestamp[i] - timestamp[i-1],  i = 1..n-1
3. Получается массив из (n-1) интервалов в секундах

Метрики интервалов:
  - Массив intervalsSec -- все интервалы
  - medianIntervalSec -- медиана интервалов

Интерпретация медианы интервала:
  < 10 сек    -- высокочастотный бот (HFT-подобное поведение)
  10-60 сек   -- автоматизированный скрипт
  1-60 мин    -- полуавтоматическая активность
  > 1 часа    -- ручное управление кошельком

Гистограмма интервалов:
  - Равномерное распределение -- случайная/ручная активность
  - Пик у нуля -- пакетная обработка (batch processing)
  - Несколько пиков -- смешанная активность (ручная + авто)

ОБНАРУЖЕНИЕ ВСПЛЕСКОВ (BURST DETECTION)
================================================================

Метод скользящего окна (sliding window):

Параметры:
  burstWindowSec  -- ширина окна в секундах (по умолчанию 3600)
  burstMinEvents  -- минимум событий в окне (по умолчанию 8)

Алгоритм:
1. Транзакции отсортированы по времени
2. Инициализация: winStart = timestamp[0], count = 1
3. Для каждой следующей транзакции i:
   a. Если timestamp[i] - winStart <= burstWindowSec:
      count++  (транзакция попадает в текущее окно)
   b. Иначе:
      Если count >= burstMinEvents: записать окно как всплеск
      winStart = timestamp[i], count = 1  (новое окно)
4. После цикла: проверить последнее окно

Результат: массив burstWindows = [{startSec, endSec, count}, ...]

Криминалистический смысл всплеска:
  - Дробление крупной суммы на множество мелких переводов
    (structuring / smurfing) -- уклонение от порогов отчётности
  - Работа mixing-сервиса (tumbler): быстрая серия входов/выходов
  - Автоматизированный вывод средств после взлома
  - Координированная атака (dust attack)

ПРИМЕР
================================================================

Транзакции в секундах: [0, 10, 20, 30, 40, 50, 60, 70, 80]
burstWindowSec = 100, burstMinEvents = 5

Шаг 1: winStart=0, count=1
Шаг 2: t=10, 10-0=10 <= 100, count=2
Шаг 3: t=20, 20-0=20 <= 100, count=3
...
Шаг 9: t=80, 80-0=80 <= 100, count=9
Конец: count=9 >= 5 --> всплеск {start:0, end:80, count:9}

Результат: 1 всплеск из 9 событий за 80 секунд.

СВЯЗЬ С ФЛАГОМ highBurstiness
================================================================

flags.highBurstiness = (burstWindows.length > 0)

Флаг устанавливается если найдено хотя бы одно burst-окно.
Это не доказательство нарушения, а индикатор для аналитика.

КОД (temporal.ts)
================================================================

export function temporalFromTransfers(rows, burstWindowSec, burstMinEvents) {
  const sorted = [...rows].sort((a,b) => a.timestampSec - b.timestampSec)

  // Вычисление интервалов
  const intervalsSec = []
  for (let i = 1; i < sorted.length; i++) {
    intervalsSec.push(sorted[i].timestampSec - sorted[i-1].timestampSec)
  }

  // Медиана интервалов
  const si = [...intervalsSec].sort((a,b) => a-b)
  const medianIntervalSec = si[Math.floor(si.length / 2)]

  // Обнаружение всплесков
  const burstWindows = []
  let winStart = sorted[0].timestampSec
  let countInWin = 1
  for (let i = 1; i < sorted.length; i++) {
    const t = sorted[i].timestampSec
    if (t - winStart <= burstWindowSec) {
      countInWin++
    } else {
      if (countInWin >= burstMinEvents) {
        burstWindows.push({startSec: winStart, endSec: sorted[i-1].timestampSec, count: countInWin})
      }
      winStart = t
      countInWin = 1
    }
  }
  // Проверка последнего окна
  if (countInWin >= burstMinEvents) {
    burstWindows.push({startSec: winStart, endSec: sorted[sorted.length-1].timestampSec, count: countInWin})
  }

  return { intervalsSec, medianIntervalSec, burstWindows }
}

ВИЗУАЛИЗАЦИЯ В ПРИЛОЖЕНИИ
================================================================

ChartsPanel отображает два варианта:

1. Если есть всплески (burstWindows.length > 0):
   Bar chart "Всплески активности" -- столбцы по количеству
   событий в каждом всплеске с подписью времени начала.

2. Если всплесков нет:
   Line chart "Интервалы -- линейный ряд" -- каждый интервал
   как точка на временной оси. Горизонтальная пунктирная линия
   показывает медиану (жёлтый цвет).

Гистограмма интервалов (всегда):
   Распределение интервалов по бинам (12 бинов).
   Позволяет визуально оценить характер активности.
